# 新手第一次使用教程

欢迎使用 AIMux！这是一个专为本地 OpenAI 和 Anthropic API 账号管理的桌面工具。它像一个智能路由器，把多个账号统一管理，并自动处理失败降级，让你的 AI 工作流更顺畅。

本教程适合新手，按照**推荐设置顺序**一步步配置，就能享受到最佳体验。

## 1. 账号设置（必须做！）

1. 启动 AIMux 后，左侧菜单点击 **账号管理**。
2. 点击 **新增账号**（或编辑已有账号）。
3. 在表单中填写必要信息：

   - **倍率（Rate Multiplier）**：这是**最重要的一步**！  
     影响请求在不同账号间的分配比例。  
     **必填，范围 0.01–0.99，默认 0.10**。

   - **支持模型**：勾选该账号支持的模型列表。  
     未勾选任何模型 = 该账号支持协议下所有模型。

   - **测试默认模型**：从支持模型列表中选择一个测试模型。  
     这个模型用于账号测试和后台监控。

**小贴士**：新增账号时先填倍率、支持模型和测试模型，再保存。测试账号时观察是否正常。

## 2. 设置页面开启账号监控（强烈推荐）

1. 左侧菜单点击 **设置**。
2. 在设置页面找到 **开启账号监控** 复选框。
3. **如果需要更好的体验，一定要打开它**（默认已开启）。

**为什么一定要开？**
- 开启后，AIMux 会在后台每 2 分钟自动 ping 所有启用账号，检查是否可用。
- 会自动调整账号优先级，让你能快速看到哪个账号最健康。
- 监控页面（可在设置或主界面查看）会展示状态格，绿色=成功、红色=失败，非常直观。
- 体验非常好，能避免你手动频繁测试账号，大大提升使用效率。

**关闭**时后台不再检查，但历史记录仍保留。

## 3. 开启上游代理（强烈推荐，尤其是国外访问）

1. 在 **设置** 页面找到 **启用上游代理** 选项。
2. **一定要打开它**。
3. 填写**上游代理地址**。

**如何获取 Clash Verge 代理地址？**

1. 打开 Clash Verge（推荐使用 **混合端口**）。
2. 在 Clash 规则或代理列表中找到你的中转站/代理节点。
3. 复制节点的 **HTTP/SOCKS5 地址**（格式通常是 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:7891`）。
4. 在 AIMux 设置中粘贴对应地址。
5. 点击保存。

**为什么一定要开？**
- 99% 的中转站、Clash 节点、代理服务器都位于国外。
- 开启代理后，AIMUX 会显式通过该代理转发请求，能显著提升速度和稳定性。
- 直连国际节点体验非常好，延迟低、速度快，远超直连。
- 关闭代理时会强制直连（不走系统代理）。

**小贴士**：
- 代理地址在设置页面保存后立即生效。
- 如果你的中转站是国内的，开启代理反而可能变慢，建议关闭。
- 首次开启建议配合账号监控一起使用。

## 4. 完成设置后建议

- 新增几个高质量账号，合理分配倍率和优先级。
- 开启账号监控和上游代理。
- 进入监控页面或使用记录查看效果。
- 账号管理中可批量测试账号可用性。

## 常见问题

- **数据保存在哪里？**  
  `%APPDATA%\aimux` 文件夹（Windows），包含数据库和配置。

- **如何查看日志？**  
  设置页面有“打开数据目录”按钮，直接打开文件夹。

- **启动慢？**  
  首次运行会自动创建虚拟环境，耐心等待。
