# 模型维护功能

## 1. 模型目录

模型目录存储在 `models` 表中，每条记录包含 ID、名称、协议类型、测试默认标记、创建时间和更新时间。同一协议类型下模型名称唯一，OpenAI 和 Anthropic 可以各自拥有同名模型。

首次启动会幂等补充默认目录：

- OpenAI：`gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`
- Anthropic：`claude-opus-5`、`claude-sonnet-5`、`claude-fable-5-1`

删除用户模型不会修改已经保存到账号上的支持模型字符串；账号编辑页会保留这类历史选择。

## 2. 页面操作

模型维护页支持按类型筛选（全部、OpenAI、Anthropic），并提供刷新、新增、编辑、删除和“设为默认”。列表按协议类型、测试默认（默认在前）、名称和 ID 排序，展示名称、类型、是否测试默认和更新时间。

新增/编辑表单只有模型名称和类型。名称会去除首尾空格，不能为空；同一类型下重复名称由服务端返回 409。编辑模型时允许修改名称和类型，切换类型会清除自身默认标记并保证旧类型仍有默认模型。

每种协议类型最多一个测试默认模型。设置默认时会先清除同类型其他模型的默认标记；删除默认模型后自动从该类型剩余模型中补选一个。

## 3. 相关接口

| 操作 | 接口 |
|---|---|
| 列表 | `GET /api/models?type=openai\|anthropic` |
| 新增 | `POST /api/models` |
| 编辑 | `PUT /api/models/{model_id}` |
| 删除 | `DELETE /api/models/{model_id}` |
| 设置默认 | `POST /api/models/{model_id}/set-default` |

协议兼容模型目录由这些记录生成：OpenAI 为 `GET /v1/models`，Anthropic 为 `GET /v1/anthropic/models`。兼容目录只包含目录中的模型名称；OpenAI 模型详情要求该模型存在于当前目录。
