## 新功能

- 倍率监控配置新增“倍率除数”，默认值为 `1`。当中转站返回的是放大后的倍率时，可配置除数进行换算，例如远端返回 `3`、除数填写 `10`，AIMux 将按 `0.3` 比较并更新账号倍率。
- 倍率监控列表新增倍率换算展示，便于直接确认每条配置使用的换算规则。

## 优化与修复

- 远端倍率使用精确十进制计算，先除以配置的倍率除数，再校验倍率范围和小数位，避免浮点精度影响比较结果。
- 前端和后端共同校验倍率除数必须为 `1～10000` 的整数；修改除数后会让该配置尽快按新规则重新检查。

## 升级说明

- 本次升级为 `multiplier_monitor_configs` 增加 `multiplier_divisor` 字段，不修改账号表和倍率监控日志表。
- SQLx migration 会为已有倍率监控配置自动填入默认值 `1`，升级后原有倍率比较行为保持不变，无需手动调整配置。
