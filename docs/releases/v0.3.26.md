## 优化与修复

- 修复流式网关在 `response.completed` 的 JSON 已收到、但 SSE 事件结束空行尚未收齐时提前关闭连接的问题，减少 Codex 因未收到完整完成事件而反复重连。
- 上游在完整结束事件到达前关闭时，使用记录改为标记失败，不再把正常 EOF 直接当作成功。
- 暂停监控轮次结束后的自动优先级提升，避免监控探测持续改变账号优先级；请求缓存等其他优先级策略不受影响。

## 升级说明

- 本次更新不涉及数据库结构变更。
- 桌面客户端和 Web 网关共用流转发逻辑；多层 AIMux 转发场景需要分别更新各层实例。
- 更新桌面应用后需要重新启动 AIMux，已运行的旧进程不会因源码或服务器升级而自动更新。
