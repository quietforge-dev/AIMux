## 新功能

- 新增每日数据统计表，按本机日期每天保存一条 Token 汇总，正常运行时每天早上 8 点后汇总昨天的数据。
- 首次升级从最早保留的使用记录开始自动回填历史，停机后再次启动会自动补齐遗漏日期，空白日期保存零值记录。
- 软件在早上 8 点后启动也会立即检查并补跑，无需在固定时间保持运行。

## 优化与修复

- 昨日统计优先读取每日汇总，尚未汇总时回退实时查询；总计合并每日汇总及未归档明细，避免重复累计。
- 今日及启用账号今日统计继续实时查询，缓存率仍按输入 Token 加权计算。
- 跨天未结束的流式请求延后汇总，归档后的迟到记录和 Token 更新自动补入对应日期。
- 手动清理使用明细前先补齐汇总，仅删除已归档且已结束的记录，清理后保留每日累计值。

## 升级说明

- 自动执行新增数据库 migration，保留原始使用记录，不自动删除明细。
- 回填仅覆盖当前数据库仍保留的历史明细，已经删除的数据无法恢复。
- 后台每分钟检查一次待汇总日期，执行失败自动重试，重复执行不会重复累计。
