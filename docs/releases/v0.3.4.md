## 新功能

- 倍率监控支持配置 refresh token。查询接口返回 401 时，系统会自动调用 `/api/v1/auth/refresh` 获取新的 access token 和 refresh token，更新配置后重试一次查询。
- 倍率监控配置改为填写站点域名，系统自动请求 `/api/v1/keys` 和 `/api/v1/auth/refresh`，同时兼容已有保存的完整查询地址。

## 优化与修复

- refresh token 轮换更新受到配置租约和版本校验保护，避免并发编辑时覆盖用户的新配置；刷新失败或重试仍返回 401 时，本轮不会更新账号倍率。
- 账号新增/编辑表单中的模型选择区域高度从 105px 调整为 180px，方便查看和选择更多模型。

## 升级说明

- 本次升级新增 `multiplier_monitor_configs.refresh_token` 字段，已有配置默认为空，不影响原有倍率监控配置。
- refresh token 不会通过列表接口返回明文；未配置 refresh token 的旧配置在遇到 401 时会记录失败并等待用户补充配置。
