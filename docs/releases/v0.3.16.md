## 优化与修复

- 监控流式探测的生成上限从 1 调整为 256 token，为推理模型预留生成空间；收到首个文本后仍立即停止读取。
- 补充流式文本和 JSON 回退响应识别，兼容分片和末尾缺少换行的响应，避免将 HTTP 200 的错误正文误判为成功。
- 区分生成额度耗尽、空响应和上游失败事件，保留更具体的失败原因。
- 真实网关请求因客户端断开或本地使用记录写入失败时，不再因此扣减账号优先级。
- 交换侧边栏菜单位置，监控管理位于数据统计上方。

## 升级说明

- 无需修改数据库结构；监控继续复用原有耗时字段。
- 真实网关请求参数保持原样转发，256 token 上限仅用于定时监控探测。
