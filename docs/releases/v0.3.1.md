## 新功能

- 新增“倍率监控”菜单，可为不同的倍率查询地址配置访问 Token，并通过左右双栏一次选择多个 AIMux 账号。
- 倍率监控每小时自动查询远端全部有效密钥及倍率，也支持在页面中立即检查；只有密钥精确匹配、倍率合法且与本地不同的账号才会更新。
- 新增倍率监控日志，可查看账号倍率更新、倍率无变化、密钥未匹配、倍率无效、账号停用、配置变更和查询失败等结果。

## 优化与修复

- 倍率查询支持自动补充 Bearer 认证、分页读取、代理、超时、响应大小限制和敏感信息保护；任意接口级查询失败都不会更新账号倍率。
- 桌面版与独立网关共用数据库时，通过数据库租约避免同一倍率监控配置被重复执行；检查过程中账号或配置发生变化时不会覆盖用户的新值。
- 优化倍率监控账号选择器布局，待选账号和已选账号固定左右排列，中间按钮纵向展示。

## 升级说明

- 本次升级新增 `multiplier_monitor_configs` 和 `multiplier_monitor_logs` 两张表，用于保存倍率监控配置和日志；不修改现有账号、模型、使用记录及账号监控表。
- 升级时会通过 SQLx migration 自动创建新表，现有账号及配置无需迁移或重新录入。
- 已使用开发版提前执行该 migration 的数据库，正式版升级时会识别已有 migration 并直接继续使用，不会重复建表。
