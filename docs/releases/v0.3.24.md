## 新功能

- 账号管理增加供应商字段，列表展示供应商名称和 Logo；新增、编辑账号支持按协议类型和供应商筛选模型。
- 账号支持开启超级优先，同协议、同供应商仅保留一个，开启新账号时自动取消原选择。账号启用、支持请求模型且优先级达到 5 时优先调度，低于 5 时恢复普通调度，恢复到 5 后自动生效。

## 优化与修复

- 切换协议或供应商时，移除不兼容的已知模型前进行确认，并同步清理受影响的测试模型和模型映射；保留自定义及未收录模型。
- 复制或通过 JSON 导入账号时保留供应商，超级优先默认关闭，避免替换本机已有选择。
- 监控比较账号时仍使用普通调度规则，原有优先级加减和倍率同步逻辑保持不变。

## 升级说明

- 本次更新通过 SQLx migration `0013` 为账号表增加供应商和超级优先字段，超级优先默认关闭，不新增唯一约束或 CHECK 约束。
- 仅对支持模型全部可识别且供应商一致的旧账号自动回填供应商；其余旧账号保留未指定，可在编辑账号时设置，已有模型配置保留。
